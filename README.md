# GRANNY_Vk:
Экспериментальный низкоуровневый 3D-игровой движок, написанный с нуля на **C++** и **Vulkan API 1.3** для операционной системы Windows (WinAPI). Проект представляет собой воссоздание механик хоррора *Granny* на базе кастомной архитектуры без использования готовых игровых движков.

##  Основные характеристики и подсистемы

- **Графическое ядро:** Полноценная инициализация Vulkan 1.3 (Instance, Validation Layers, Swapchain, Image Views, Render Pass, Framebuffers, Command Pools/Buffers).
- **Искусственный Интеллект (Predictive AI):** Модульный ИИ противника на базе конечного автомата (FSM). Реализует комбинированную систему поиска пути: глобальное патрулирование по умным точкам-ориентирам (Waypoints) с предиктивным анализом маршрутов и локальное преследование цели в непрерывном пространстве.
- **Физическая подсистема и Коллизии:** Просчет столкновений в реальном времени на основе выравнивания по осям (Axis-Aligned Bounding Boxes — AABB) для игрока и статических объектов уровня.
- **Трассировка лучей (Raycasting):** Кастомная подсистема сканирования геометрии уровня (Ray-AABB Box Intersection) и просчета зеркальных отражений лучей по законам линейной оптики.
- **Система ввода:** Аппаратный захват мыши (WinAPI Mouse Hook / Clipping) для свободного 3D-обзора и неблокирующий опрос клавиатуры.
- **Производительность:** Высокоточный таймер deltaTime (`std::chrono`), обеспечивающий независимость физики от частоты кадров. Движок демонстрирует производительность в диапазоне 70,000–100,000+ FPS в режиме симуляции на GPU AMD Radeon RX 6600.

##  Стек технологий
- **Язык:** C++17 / C++20
- **Графический интерфейс:** Vulkan SDK (vulkan.hpp C++ Wrapper)
- **Математика:** GLM (OpenGL Mathematics)
- **ОС API:** Windows API (Win32)

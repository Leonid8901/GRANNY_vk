                    GRANNY_Vk: ENGINE DATA ARCHITECTURE MAP

1. SUBSYSTEM: CORE ENGINE CLASS (Engine.h / Engine.cpp)
--------------------------------------------------------------------------------
* m_window          [std::unique_ptr<Window>]        - Умный указатель на WinAPI-окно. Инкапсулирует обработку системных событий ОС.
* m_vulkan          [std::unique_ptr<VulkanContext>] - Умный указатель на графический контекст Vulkan API 1.3. Мост взаимодействия с GPU.
* m_lastFrameTime   [std::chrono::time_point]        - Точка отсчета времени. Хранит точное системное время завершения предыдущего кадра.
* m_player          [std::unique_ptr<Player>]        - Умный указатель на объект кинематического контроллера персонажа игрока.
* m_granny          [std::unique_ptr<Granny>]        - Умный указатель на объект контроллера искусственного интеллекта противника.
* m_mapSystem       [std::unique_ptr<MapSystem>]     - Умный указатель на подсистему физических стен уровня и трассировки лучей.
* m_houseMap        [HouseMap]                       - Объект виртуальной навигационной сетки и логического зонирования комнат.
* m_currentRoomName [std::string]                    - Строковый идентификатор текущего сектора (комнаты), в котором находится игрок.
* m_isPaused        [bool]                           - Флаг состояния конечного автомата игры. true = симуляция приостановлена.
* m_escWasPressed   [bool]                           - Регистровый флаг состояния клавиши ESC в предыдущем кадре (защита от дребезга ввода).
* deltaTime         [float]                          - Время кадра. Скалярная разница в секундах между итерациями цикла. Базис физики.
* fpsTimer          [float]                          - Накопительный таймер секунд для расчета и вывода метрик производительности.
* frameCount        [int]                            - Счетчик итераций игрового цикла (кадров), выполненных за одну секунду.

2. SUBSYSTEM: KINEMATIC ACTOR CONTROLLER (Player.h / Player.cpp)
--------------------------------------------------------------------------------
* m_position        [glm::vec3]                      - Радиус-вектор положения персонажа в трехмерном евклидовом пространстве {X, Y, Z}.
* m_front           [glm::vec3]                      - Нормализованный вектор направления взгляда персонажа (длина равна 1.0f).
* m_up              [glm::vec3]                      - Константный ортонормальный вектор направления "Вверх" в системе координат {0.0f, 1.0f, 0.0f}.
* m_speed           [float]                          - Скалярная величина базовой линейной скорости перемещения персонажа (м/с).
* m_yaw             [float]                          - Угол поворота камеры вокруг вертикальной оси (рыскание/горизонт). Начальное значение: -90.0f.
* m_pitch           [float]                          - Угол наклона камеры вокруг поперечной оси (тангаж/вертикаль). Диапазон ограничений: [-89.0f; 89.0f].
* xOffset           [float]                          - Динамическое смещение курсора мыши по горизонтали относительно центра окна в пикселях.
* yOffset           [float]                          - Динамическое смещение курсора мыши по вертикали относительно центра окна в пикселях.

3. SUBSYSTEM: PREDICTIVE ARTIFICIAL INTELLIGENCE (HouseAI.hpp)
--------------------------------------------------------------------------------
* m_position        [glm::vec3]                      - Координаты физического нахождения сущности противника в мировом пространстве.
* m_speed           [float]                          - Линейная скорость перемещения сущности. В режиме Chasing автоматически увеличивается в 1.5 раза.
* m_state           [GrannyState]                    - Текущее состояние конечного автомата (FSM) ИИ: Patrolling, Resting или Chasing.
* m_targetIdx       [size_t]                         - Индекс активного целевого навигационного узла (Waypoint) из вектора карты.
* m_stateTimer      [float]                          - Фиксированный таймер удержания состояния Resting для симуляции осмотра и кэширования путей.
* m_noisePos        [glm::vec3]                      - Вектор координат зафиксированного акустического импульса (место падения предмета).
* m_hasNoise        [bool]                           - Триггерный флаг наличия активного акустического целеуказания для перехвата траектории патрулирования.

4. SUBSYSTEM: GRAPHICS INFRASTRUCTURE (VulkanContext.h / VulkanContext.cpp)
--------------------------------------------------------------------------------
* m_instance        [vk::Instance]                   - Системный дескриптор связи приложения с программным интерфейсом Vulkan API 1.3.
* m_debugMessenger  [vk::DebugUtilsMessengerEXT]     - Дескриптор перехвата логов и обработки ошибок слоев валидации Khronos Group.
* m_physicalDevice  [vk::PhysicalDevice]              - Ручка управления выбранным аппаратным графическим адаптером (discrete GPU).
* m_device          [vk::Device]                     - Дескриптор логического устройства для управления памятью, очередями и буферами.
* m_graphicsQueue   [vk::Queue]                      - Очередь для отправки графических командных пакетов на выполнение видеочипу.
* m_surface         [vk::SurfaceKHR]                 - Дескриптор абстрактной поверхности отрисовки, связывающий Vulkan с подсистемой WinAPI WSI.
* m_swapChain       [vk::SwapchainKHR]               - Объект цепочки создания и смены отображаемых фреймбуферов (Double/Triple Buffering).
* m_swapChainImages [std::vector<vk::Image>]         - Контейнер сырых текстурных массивов картинок, выделенных внутри Свопчейна.
* m_swapChainImageViews [std::vector<vk::ImageView>] - Контейнер интерфейсов ("окон доступа") для чтения/записи в картинки Свопчейна.
* m_swapChainImageFormat [vk::Format]                - Цветовой формат буфера кадра. Жестко инициализирован как vk::Format::eB8G8R8A8Unorm.
* m_swapChainExtent [vk::Extent2D]                   - Двухмерные геометрические размеры картинок рендеринга (разрешение кадра 1280x720).
* m_renderPass      [vk::RenderPass]                 - Паспорт прохода отрисовки. Описывает аттачменты холста, подпроходы и операции очистки.
* m_swapChainFramebuffers [std::vector<vk::Framebuffer>] - Контейнер объектов физической связи Render Pass с конкретными ImageView.
* m_commandPool     [vk::CommandPool]                - Системный пул выделения и управления памятью для командных списков графики.
* m_commandBuffer   [vk::CommandBuffer]              - Буфер записи низкоуровневых GPU-команд (очистка, биндинг конвейеров, отрисовка).
* imageIndex        [uint32_t]                       - Индекс доступного свободного фреймбуфера, возвращенный видеокартой через acquireNextImage.
* clearColor        [vk::ClearValue]                 - Структура цвета очистки экрана. Настроена на тёмно-синий тон хоррора (0.02, 0.04, 0.15, 1.0).

5. SUBSYSTEM: PHYSICAL MAP & GEOMETRY STRUCTURES (MapSystem.hpp / Ray.hpp)
--------------------------------------------------------------------------------
* walls             [std::vector<CollisionBox>]      - Массив всех твердых геометрических AABB-коробок (стен, шкафов, кроватей) на уровне.
* waypoints         [std::vector<glm::vec3>]         - Массив векторов-ориентиров для глобального поиска путей ИИ внутри HouseMap.
* min               [glm::vec3]                      - Базисная точка левого-нижнего-ближнего угла AABB-коробки.
* max               [glm::vec3]                      - Базисная точка правого-верхнего-дальнего угла AABB-коробки.
* origin            [glm::vec3]                      - Радиус-вектор точки старта испускаемого луча трассировки (глаза Леонида).
* direction         [glm::vec3]                      - Нормализованный вектор направления движения луча в пространстве.
* hitPoint          [glm::vec3]                      - Вектор координат точки физического пересечения луча со стеной или полом.
* normal            [glm::vec3]                      - Перпендикулярный вектор плоскости (нормаль) в точке столкновения луча.
* t / distance      [float]                          - Скалярное расстояние в метрах от точки origin до точки hitPoint.
* hit               [bool]                           - Логический флаг факта пересечения геометрии. true = коллизия зафиксирована.
